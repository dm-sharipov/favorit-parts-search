# Подбор автозапчастей

Поиск по артикулу через API «Проценка» Favorit Parts: сначала производители, потом аналоги и предложения.

React, Redux Toolkit, Bootstrap, Vite.

## Запуск

```bash
npm install
npm run dev
```

Ключ взят из документации API. Для проверки: `0189`, `7160500039S`.

## Заметки

- Цена и остаток берутся со складов: поле `price` в документации помечено «не использовать».
- Если деталь не найдена, API возвращает пустую запись — она отфильтровывается.
- Приложение нужно открывать по http: API работает по http, и со страницы на https браузер запрос заблокирует.
