# Подбор автозапчастей

Поиск по артикулу через API «Проценка» Favorit Parts: сначала производители, потом аналоги и предложения.

React, Redux Toolkit, Bootstrap, Vite.

## Запуск

```bash
npm install
npm run dev
```

Ключ взят из документации API. Для проверки: `0189`, `7160500039S`.

## Заметки

- Цена — лучшая среди складов, остаток — сумма по всем складам: поле `price` у товара в документации помечено «не использовать». В таблице сначала 50 позиций, остальные по кнопке «Показать ещё».
- Если деталь не найдена, API возвращает пустую запись — она отфильтровывается.
- У демо-ключа есть лимит запросов. Если он превышен, можно подождать или выбрать другого производителя.
- Приложение нужно открывать по http: API работает по http, и со страницы на https браузер запрос заблокирует.

## Вёрстка

- На мобильных таблица перестраивается в карточки.
- Bootstrap подключён в каскадный слой (`src/styles/index.css`), поэтому свои стили висят на простых БЭМ-классах без борьбы со специфичностью.
- Из Bootstrap взяты только компоненты: кнопки, таблица, форма, алерты. Отступы и раскладка написаны в CSS, без утилит.
- Медиазапросы записаны в range-синтаксисе: `(width < 768px)` вместо `(max-width: 767.98px)`.
- Слои и range-синтаксис выбраны намеренно, ради читаемости кода. Они работают в Chrome 104, Safari 16.4, Firefox 97 и новее. Если нужна поддержка более старых браузеров, Bootstrap можно подключить обычным импортом и усилить свои селекторы, а брейкпоинты записать через `max-width`.
